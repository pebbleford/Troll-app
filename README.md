# 😈 Troll Remote

Prank your friend while they play on your PC, using your iPad as the remote.
Jumpscares, creepy sounds, fake crashes, spiders crawling over the screen, and
the PC talking to them out loud.

- **On the PC:** a small app sits invisibly on top of the game. Effects appear
  over the game, and clicks still go through to it, so your friend can keep playing.
- **On the iPad:** a web page with big buttons. There is nothing to install, just scan a QR code.

## Setup (Windows)

1. Install **Node.js LTS** from <https://nodejs.org> (one time only).
2. Download this project (green **Code** button → **Download ZIP**) and unzip it.
3. Double-click **`start.bat`**. The first run takes a minute while it installs.
4. If Windows Firewall asks, click **Allow access** (Private networks). The iPad
   can't connect without this.
5. A window with a QR code opens. Scan it with the iPad camera (same Wi-Fi as the PC).
6. The first time, it asks if it should **start automatically when the PC turns on** —
   say yes so it's ready before your friend sits down. (You can change this any time
   with the checkbox in the window, or in the tray menu.)
7. Click **Hide to tray**. The app keeps running in the little icon at the
   bottom-right (the system tray) — click that icon any time to open it again.

Mac/Linux: run `./start.sh` instead.

Tip: in Safari, tap **Share → Add to Home Screen** to put the remote on your iPad's
home screen like an app. You'll need to enter the 6-letter code (or sign in) once.

## What's on the remote

| Scares | Sounds | Other |
|---|---|---|
| Jumpscare (face + scream) | Air horn, fart, scream | **Make the PC talk** (text-to-speech, with deep/creepy/chipmunk voices) |
| Flashbang | Knocking, footsteps, whispers | **Text on screen** (creepy, meme or popup notice) |
| Fake blue-screen crash | Mosquito buzzing around your head | **Emoji rain** 💩🤡💀 |
| Cracked screen | Heartbeat, phone ringing, doorbell | **Your own files**: upload a pic and use it as a jumpscare, or play your own sounds and videos |
| Spiders crawling | Siren, explosion, glass break | **Delay**: fire in 3s/10s/30s/1min/random so you can act innocent |
| Ghost walking past | Creepy ambience, static | **👻 Haunt mode**: random creepy noises and sightings every 20–75 s |
| Glowing eyes in the dark | | **🧨 Close apps**: close their game/app from the iPad |
| Blackout / TV static | | **Volume** slider and **⛔ STOP ALL** |

All sounds and scary pictures are generated by the app itself, so there are no files to download.
The footsteps, whispers and mosquito move between the left and right speakers, which is extra
spooky if your friend wears headphones.

### Custom jumpscares & sounds

Upload your own pictures, sounds and videos from the iPad (or drop them in the
`media` folder on the PC). Then tap a file to:

- use a **picture** as a jumpscare — and optionally pick one of your uploaded
  **sounds** to play with it instead of the built-in scream, so you can make your
  own custom jumpscare;
- just pop a picture up on screen;
- play a sound or a full-screen video.

### Close their game from the iPad

The **🧨 Close apps on the PC** section lists the apps your friend currently has
open (only things with a window). Tap one and it closes — to them it just looks
like the game crashed. Windows' own critical system processes are never listed
and can't be closed, so you can't break the PC.

## Use it from anywhere (optional sign-in, no QR)

Out of the box the iPad and PC must be on the **same Wi-Fi**. If you'd rather sign
in with an account and control the PC from **anywhere** (and skip the QR/code), set
up a free Firebase project — about 5 minutes:

1. Go to <https://console.firebase.google.com> → **Add project**.
2. **Build → Authentication → Get started** → enable **Email/Password**.
3. **Build → Firestore Database → Create database** (Production mode). In the
   **Rules** tab, paste the rules below and **Publish**.
4. **Project settings (gear) → General → Your apps →** the web icon `</>`.
   Register an app and copy the config values it shows.
5. **Authentication → Users → Add user**: create one login (email + password).
   You'll use that same login on the PC and the iPad — that's what pairs them.
6. In the Troll Remote folder, copy **`firebase-config.example.js`** to
   **`firebase-config.js`** and paste in your config values.
7. Restart Troll Remote. A **Sign in** box appears in the PC window and on the
   iPad page. Sign in on both with that one account — done. The PC remembers the
   sign-in between restarts.

When both devices are on the same Wi-Fi it still uses the fast direct connection
automatically; otherwise it relays through your Firebase project. The 6-letter
code keeps working too, as a fallback.

**Firestore security rules** (so only your account can see your data):

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}
```

The values in `firebase-config.js` are **not secrets** (web apps ship them); your
data is protected by these rules plus your account password. `firebase-config.js`
is git-ignored so you won't commit it by accident.

> Note: the cloud sign-in is wired up but, unlike the local Wi-Fi mode, I couldn't
> test it against a live Firebase project from here — so give it a quick try at home
> first. Uploading new files and photo thumbnails still need the same Wi-Fi; firing
> effects, talking, and closing apps all work over the cloud.

## Good to know

- **Scares not showing over the game?** Set the game's display mode to
  **Borderless** or **Windowed fullscreen**. Old-style "exclusive fullscreen" games
  draw over everything. Sounds always work either way.
- **Emergency stop** on the PC: `Ctrl+Alt+Shift+X`. Show the window again:
  `Ctrl+Alt+Shift+T`, or click the tray icon (bottom-right).
- **Starts with the PC**: toggle it in the window or the tray menu. When it
  auto-starts it opens straight to the tray, hidden.
- **Multiple monitors?** Right-click the tray icon → *Show scares on screen* to pick one.
- **Your own media:** drop files in the `media` folder, or upload them from the
  iPad. Images, mp3/wav/ogg/m4a sounds and mp4/webm videos are supported.
- **iPad can't connect?** Make sure both are on the same Wi-Fi (not a guest network),
  allow the app through the firewall, and try the other addresses listed under the QR code.
- Only someone with the 6-letter code (or, if you set up sign-in, your account)
  can control it. The code is saved in your user settings and stays the same
  between runs.
- The port is 4545 by default. Set the `TROLL_PORT` environment variable to change it.
